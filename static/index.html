NEBIUS TOKEN FACTORY

Connect the investigator.

The simulator works locally. Live AI investigation requires your own Nebius API key.

  1. Get a Token Factory API key in your Nebius account.
  2. Create .env.local beside server.py with NEBIUS_TOKEN_FACTORY_KEY=your-key.
  3. Restart the local server and reload this page.

The server selects an available NVIDIA Nemotron text model. You can set NEBIUS_MODEL to its exact ID. Keys stay on the server; never enter them into a scenario.

Live runs send your concern and synthetic test measurements to Nebius and may consume credits. A run makes at most 8 proposal calls. No real driving footage is uploaded.
